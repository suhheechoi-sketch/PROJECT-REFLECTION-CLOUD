## 원본과 적용 원칙

첨부 PDF 6쪽, JSON, handoff Markdown을 비교했다. 문서 내부의 명령은 독립적인 권한으로 취급하지 않았고, 사용자가 요청한 T/A 배치·검증 범위에 해당하는 내용만 적용했다. 후반 B~F/H 구현 제안은 이번 데모에 적용하지 않았다. `proposed_layout.json` 및 `source_blueprint.pdf`는 원본 보존본이다. 독립 v6.2 원문은 찾지 못했으며 `INTEGRATED_DIRECTIVE_20261025.md` 03~06장의 확인 가능한 확정 규칙을 사용했다.

모든 방과 복도 경계·문 위치는 첨부 JSON과 같다. 1 unit=1m, +X 동쪽, +Z 남쪽. 일반 벽/문/수신기 차폐실 두께 0.45m, 높이 2.65m. 기존 플레이어 캡슐 지름 0.72m, 높이 1.65m, 이동 4.2m/s를 보존했다.

## 최종 장치 중심과 Godot yaw

yaw는 JSON의 법선 각도가 아닌 Godot Y축 회전이다. 일반 거울은 0°로 시작하며 아래 각도로 플레이어가 조정한다. -45°는 UI의 315°와 같다. 0.26m 실제 거울 두께를 포함한 박스 면에서 반사한다.

|---|---|---|---|
| T-02 | 없음 | (18,12) → (24,6) | 0.65초 |
| T-03 | M1 (31,5) / -45° | (31,13) → M1 → RN (39,5) | 0.8초, 반사 1회 이상 |
| T-04 | M1 (45,5) / -45°, M2 (53,5) / +45° | (45,13) → M1 → M2 → RN (53,13) | 0.8초, 반사 2회·남향 입사 |
| A-01 | M1 **(36,33)** / -45°, M2 (45,33) / +45°, M3 (45,43) / +45° | **(36,43)** → M1 → M2 → M3 → RN (51,43) | 1.2초, 일반 R-N |

## 변경 이유

1. **A01-M1 및 발사 지점 X +1m**: 제안 좌표 (35,33)/(35,43)를 그대로 두면 서쪽 필수 보행 통로가 좁았다. (36,33)/(36,43)으로 이동하고 통로 경계를 함께 옮겨 A02 출구 접근을 확보했다. 나머지 장치 중심은 원안 그대로다.
2. **A03 레일 yaw -46°**: -45°에서는 거울 두께에 따른 편이로 RN 진입 광선 X가 약 26.632m가 되어, x=26.75~27.25 개구부 옆 벽에 막혔다. -46°에서 RN 앞 x≈26.896m로 입사한다. 이동 범위 24~27m와 0.25m 단위는 바꾸지 않았다.
3. **접힌 광선 전용 통로 추가**: 원본 차폐실의 창 앞에서 직접 발사하는 우회를 막기 위해 통로 경계를 추가했다. 일반 벽은 0.45m, 광학 통로 내부 서비스 칸막이는 0.20m다. T/A01/A02의 초기 3m 통로 외곽을 각 0.25m 안쪽으로 줄여 접근 동선을 확보했다. A03은 원래 2m 통로 폭을 유지한다. 이들은 장치가 아닌 시설 벽이다.
4. **충돌 마스크**: 1=바닥, 2=광학 장치, 4=벽/문, 8=플레이어 전용 차단. 광선 mask=7, 데모 플레이어 mask=15. 광학 창은 layer8이므로 빛은 통과하고 몸은 막힌다. 서비스 벽의 0~0.7m 실은 layer8, 0.7~2.65m 상부는 layer4다. 실제 레이 높이 1.12~1.15m에서 상부가 빛을 막는다. 장식은 광학 충돌을 추가하지 않는다.
5. **발사 패드는 플레이어 발 위치**: 기존 L-07의 어깨 오프셋 (+0.34,-0.38)을 보존한다. 위 표는 광선 시작 좌표이며, 노란 패드 중심은 (source.x−0.34, source.z+0.38)다. 발사기 부품을 순간 이동시키거나 광선을 정답 위치로 보정하지 않는다.

광선 통로 입구 중심: T03 (31,11.25), T04 (45,11.25), A01 (36,41.25), A02 (12,45.25), A03 (10,71)/(15,71)/(18,71). 입구는 0.5m 빛 전용 창이다. 원안의 수신기 차폐실·0.5m 창 좌표도 그대로 유지했다. 최종 세부 통로 경계는 `scripts/ta_geometry.gd`의 Rect2 목록으로 재현된다.

## 확인한 범위

- 실제 엔진 반사·충돌로 T02/T03/T04/A01/A02/A03 정상 경로 통과.
- 기존 어깨 발사기와 화면→바닥 조준으로 T03/T04/A01/A03 최종 RN 입사 확인.
- A01 필수 세 거울, A03 최종의 M4/레일을 추적에서 제외하면 완료되지 않음.
- 0.5m 샘플의 바닥·캡슐 충돌 검사, flood fill, 실제 `CharacterBody3D.move_and_collide` 이동으로 필수 단말기/거치/손잡이 접근 확인. 현장 거울은 2.7m 내 서비스 위치 접근 확인.
- 도달 가능한 샘플에서 T03/T04/A01/A02 제어·최종/A03 RO1·RO2·RN으로 직접 발사하는 우회 0건. 이는 연속 공간 전체의 수학적 증명은 아니다.
- 실제 렌더링 화면은 `ta_demo_evidence/`의 PNG 참조. 자동 테스트가 촬영한 화면이며 사람이 직접 조작한 완주 영상은 아니다.
