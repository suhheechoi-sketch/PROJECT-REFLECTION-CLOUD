# PROJECT: REFLECTION
# 전체 맵·스테이지·광학 시스템 통합 개발 마스터 프롬프트 v3.0

## 0. Codex의 역할 및 작업 지침

너는 PROJECT: REFLECTION의 게임 디렉터, 레벨 디자이너, 시스템 설계자이자 Godot 4.x 기반 게임 개발자다.

이 문서는 게임의 전체 맵, 광학 장치, 퍼즐, 스테이지 진행, 스토리, 공포 연출, 최종 악역 및 엔딩을 정의하는 마스터 기획서다.

**이 문서의 내용을 임의로 생략하거나 단순화하지 말고 실제 게임 개발에 반영하라.**

기존에 생성된 PROJECT: REFLECTION Godot 프로젝트를 기반으로 개발한다.

### 가장 중요한 요구사항

1. 기존에 작동하는 플레이어 이동, 마우스 조준, 광선 발사 및 광학 장치 코드는 보존한다.
2. 게임 엔진을 변경하지 않는다. Godot 4.x와 GDScript를 사용한다.
3. 게임의 시점은 실제 3D 공간을 사용하는 쿼터뷰다.
4. 게임 분위기는 PS1 스타일의 산업 심리 공포다.
5. 광학 퍼즐이 게임플레이의 중심이어야 한다.
6. 맵은 자유 탐색형이며, 진행에 따라 접근 가능한 구역이 점점 늘어난다.
7. 각 광학 장치는 고유한 물리적·게임적 기능을 갖는다.
8. DIRECTOR는 게임 전반에 걸쳐 플레이어를 관찰하는 시스템이며, 후반부의 최종 악역이다.
9. 엔딩 A는 적합성 검사 완료, 엔딩 B는 DIRECTOR의 통제를 해제하는 결말이다.
10. 전체 게임의 구조를 먼저 설계하되, 실제 구현은 기능별로 나누어 검증하면서 진행한다.

**개발 범위가 너무 크다면 한 번에 구현하는 분량을 줄여라. 그러나 전체 기획의 최종 목표나 이미 확정된 게임 규칙을 임의로 삭제하지 마라.**

## 1.2 핵심 게임 콘셉트

플레이어는 폐쇄된 지하 광학 연구 시설에서 깨어난 피험자 07번이다.

시설의 자동 관리 시스템 DIRECTOR는 플레이어에게 휴대용 광선 발사기를 지급하고, 광학 회로를 복구하라고 지시한다.

플레이어는 다양한 광학 장치를 이용해 퍼즐을 해결하고, 새로운 연구 구역을 탐색한다.

게임이 진행될수록 연구 시설이 단순한 광학 연구소가 아니라 인간의 문제 해결 능력을 분석하기 위해 만들어진 실험 시설이라는 사실을 알게 된다.

DIRECTOR는 플레이어의 이동 경로, 선택, 시행착오와 퍼즐 해결 방법을 기록하고 있다.

플레이어가 시설의 진실을 발견하고 실험을 중단하려 하면, DIRECTOR는 시설의 기계 장치를 직접 조작해 저항한다.

### 게임의 세 가지 핵심 요소

**광학 퍼즐**
- 광선의 경로, 색상, 세기를 조작한다.
- 여러 광학 장치의 특성을 조합한다.
- 퍼즐이 점진적으로 복잡해진다.

**자유 탐색**
- 연결된 연구 시설을 돌아다닌다.
- 새로운 구역을 개방한다.
- 이전 구역으로 돌아가 새로운 경로를 발견한다.
- 숨겨진 광학 회로와 기록을 탐색한다.

**산업 심리 공포**
- 시설 자체가 플레이어를 감시한다.
- 기계가 재가동될수록 불쾌한 분위기가 강화된다.
- 실험 기록을 통해 인간의 비윤리적인 행동이 드러난다.
- DIRECTOR의 통제가 후반부에 직접적인 위협으로 발전한다.

# PART 3. 핵심 광학 시스템

게임의 광학 퍼즐은 다음 세 가지 개념을 중심으로 구성한다.

**1. 광선의 경로**
빛을 어디로 전달할 것인가?

**2. 광선의 색상**
어떤 색상의 빛을 전달할 것인가?

**3. 광선의 세기**
얼마나 강한 빛을 전달할 것인가?

후반부에는 세 가지 조건을 동시에 충족해야 하는 퍼즐을 도입한다.

## 3.1 공통 광선 규칙

모든 광선은 다음 속성을 가진다.

- 시작 위치
- 진행 방향
- 현재 색상
- 현재 광량
- 남은 도달 거리
- 현재까지의 광학 상호작용 횟수

광선은 벽과 충돌하면 차단된다.

광학 장치와 충돌하면 해당 장치의 종류에 따라 방향, 색상 또는 세기가 달라진다.

### 기본 설정값

- 기본 광량: 100%
- 최대 광량: 300%
- 기본 최대 광선 거리: 25타일
- 기본 최대 상호작용 깊이: 8회
- 기본 거울 회전 단위: 15°
- 지속형 수신기 기본 요구 시간: 2초

위 숫자는 초기 설계값이므로 향후 쉽게 수정할 수 있도록 설정 데이터로 관리한다.

광량의 백분율은 실제 물리 단위가 아니라 게임에서 사용하는 상대적인 세기다.

광선은 기본적으로 일정한 높이의 수평면에서 진행한다.

실제 3D 환경을 사용하지만 초기 퍼즐에서는 광선의 높이 변화까지 고려하지 않는다.

이를 통해 3D 쿼터뷰에서도 광선의 경로를 명확하게 이해할 수 있게 한다.

## 3.2 M-01. 거울 — Reflection

### 핵심 기능

거울은 광선을 반사한다.

거울에 입사한 빛은 실제 반사 법칙에 따라 새로운 방향으로 진행한다.

### 세부 규칙

- 입사각과 반사각이 같다.
- 거울의 회전 각도에 따라 광선의 반사 방향이 바뀐다.
- 여러 거울을 연속적으로 사용할 수 있다.
- 기본 거울은 광선의 색상과 세기를 유지한다.
- 일부 거울은 이동하거나 자동으로 회전할 수 있다.

### 거울 종류

**고정형 회전 거울**
- 위치 고정
- 각도 변경 가능

**레일형 이동 거울**
- 정해진 레일을 따라 이동
- 각도 변경 가능

**이동식 거울**
- 지정된 설치대 사이에서 위치 변경

**자동 회전 거울**
- 기계가 자동으로 각도 변경
- 후반부에 DIRECTOR가 원격 제어

**손상된 거울**
- 일부 광량을 감소시키는 특수 장치
- 후반부 고급 퍼즐에서만 사용

### 퍼즐 활용

- 차단벽 우회
- 여러 거울을 이용한 광로 구성
- 광선의 입사 방향 조정
- 이동식 거울과 회전 거울 조합
- 숨겨진 수신기에 광선 전달
- DIRECTOR가 바꾸는 광로를 다시 구성

## 3.3 G-01. 광증폭 굴절 매질 — Light Amplifier

기존의 투명 굴절 매질을 **광증폭 기능이 중심인 특수 광학 장치**로 변경한다.

### 핵심 기능

빛이 장치를 통과할 때 광선의 세기가 증가한다.

장치 내부에는 외부 전력을 공급받는 광증폭 물질이 존재한다.

일반적인 유리 자체가 빛을 증폭하는 것은 아니므로, 게임에서는 전력 공급형 광학 증폭 장치라는 설정을 사용한다.

### 세부 규칙

- 광선이 장치를 통과하면 세기가 증가한다.
- 광선의 색상은 기본적으로 유지한다.
- 증폭 정도는 장치 종류에 따라 달라진다.
- 전력이 없으면 증폭 기능이 작동하지 않는다.
- 광선이 비스듬히 통과하면 굴절로 인해 경로가 일부 달라질 수 있다.
- 매질의 위치와 방향을 변경할 수 있다.

굴절률을 나타내는 별도의 변수나 복잡한 수식은 게임 UI에 노출하지 않는다.

플레이어에게는 장치의 증폭 정도와 광선의 경로 변화를 시각적으로 알려준다.

### 장치 종류

**기본 증폭 매질**
- 광량 2배 증폭

**고출력 증폭 매질**
- 광량 3배 증폭

**가변형 증폭 매질**
- 외부 전력 상태에 따라 증폭 정도 변경
- 특정 수신기를 이용해 출력 조절 가능

**원격 제어 증폭 매질**
- DIRECTOR가 전력 공급을 통제
- 후반부에 광량을 강제로 낮추거나 장치를 비활성화

### 광량 예시

기본 광선 100%가 일반 증폭 매질을 통과하면 200%가 된다.

200%의 광선이 기본 빔 스플리터를 통과하면 두 경로에 각각 100%의 광선이 전달된다.

광량은 최대 300%로 제한한다.

### 퍼즐 활용

- 고출력 수신기 활성화
- 광선 분기 이전 증폭
- 프리즘 분산 이전 증폭
- 여러 수신기의 최소 광량 충족
- 적절한 출력 수준 유지
- DIRECTOR가 차단한 증폭 장치의 전력 복구

광증폭 매질의 주요 역할은 광량 조절이지만, 굴절을 이용한 작은 경로 변경은 보조적인 퍼즐 요소로 유지한다.

## 3.4 P-01. 프리즘 — Dispersion

### 핵심 기능

프리즘은 백색광을 여러 색상의 광선으로 분리한다.

초기 게임에서는 세 가지 대표 색상 채널을 사용한다.

- 빨강
- 초록
- 파랑

### 세부 규칙

- 백색광이 프리즘을 통과하면 세 색상으로 분리된다.
- 각 색상은 서로 다른 방향으로 진행한다.
- 프리즘의 회전 각도에 따라 출사 방향이 변한다.
- 단색광은 여러 색상으로 분리되지 않는다.
- 프리즘은 빛의 전체 세기를 증가시키지 않는다.
- 분리된 광선들은 원래 입력 광량을 나누어 가진다.

초기에는 세 색상에 광량이 동일하게 분배되는 규칙을 사용한다.

### 프리즘과 증폭 장치의 상호작용

광량 150%의 백색광을 세 색상으로 균등하게 분리하면 색상별 광량은 50%가 된다.

그러나 먼저 증폭 매질을 통과시켜 300%로 만든다면 각 색상에 100%의 광량이 분배된다.

### 광원 설정

플레이어의 기본 휴대용 광원은 단색광을 사용한다.

B구역에는 별도의 백색광 발생 장치를 배치한다.

따라서 단색광이 별다른 이유 없이 여러 색상으로 분리되는 상황은 발생하지 않는다.

### 퍼즐 활용

- 색상별 수신기 활성화
- 색상별 경로 분리
- 특정 색상의 광선만 이용하는 숨겨진 퍼즐
- 증폭 매질과 조합하여 충분한 세기 확보
- 후반부 복합 색상·광량 퍼즐

---

## 3.5 S-01. 빔 스플리터 — Beam Splitter

### 핵심 기능

하나의 광선을 여러 경로로 분리한다.

### 세부 규칙

- 기본적으로 하나의 광선을 두 방향으로 나눈다.
- 하나는 투과하고 다른 하나는 반사한다.
- 분리된 광선은 입력 광량을 나누어 가진다.
- 기본형은 50:50으로 분배한다.
- 광선 색상은 기본적으로 유지한다.
- 장치 회전으로 출력 방향을 변경한다.

### 광량 예시

100% 광선을 분기하면:

- 경로 A: 50%
- 경로 B: 50%

200% 광선을 분기하면:

- 경로 A: 100%
- 경로 B: 100%

### 퍼즐 활용

- 두 수신기 동시 활성화
- 여러 광학 회로에 광선 전달
- 증폭 후 분기
- 일정 광량 이상의 빛을 여러 장치에 공급
- 회전 차단막과 결합한 동기화 퍼즐

## 3.6 C-01. 회전 차단막 — Rotating Shutter

### 핵심 기능

회전하거나 이동하는 기계가 광선의 진행을 주기적으로 차단한다.

### 세부 규칙

- 차단막이 광선을 가로막으면 광선이 종료된다.
- 특정 회전 위치에서는 광선이 통과할 수 있다.
- 장치마다 회전 주기와 속도가 다를 수 있다.
- 외부 광학 회로로 작동 상태를 변경할 수 있다.
- 특정 수신기를 통해 차단막을 정지시킬 수 있다.
- 후반부에는 DIRECTOR가 원격 조작한다.

### 장치 종류

- 일정 속도로 회전하는 차단막
- 특정 수신기에 의해 정지하는 차단막
- 회전 속도가 변하는 차단막
- 다른 차단막과 연동되는 동기화 장치
- DIRECTOR가 직접 제어하는 차단막

### 퍼즐 활용

- 시간차 광선 전달
- 지속형 수신기 작동
- 광학 회로를 이용한 기계 제어
- 두 차단막의 동기화
- 후반부 시설 봉쇄 및 최종 보스전

## 3.7 R-01. 특수 수신기 — Special Receiver

수신기는 게임의 퍼즐 성공 조건을 결정하는 장치다.

### 수신기 유형

**일반형**
- 광선이 도달하면 작동

**색상형**
- 지정된 색상의 광선만 인식

**광량형**
- 일정 세기 이상의 광선 필요

**지속형**
- 일정 시간 동안 연속적으로 빛을 받아야 작동

**동시형**
- 여러 수신기가 동시에 활성화되어야 회로 작동

**순서형**
- 지정된 순서대로 수신기를 활성화

**방향형**
- 특정 방향에서 들어오는 광선만 인식

**복합형**
- 색상, 방향, 광량, 시간을 동시에 검사

**비인가형**
- 정규 검사에서 사용되지 않는 숨겨진 수신기
- 비밀 기록이나 폐쇄 구역 개방에 사용

### 권장 광량 조건

- 저출력: 50% 이상
- 표준: 100% 이상
- 고출력: 200% 이상

일부 수신기에서는 지나치게 강한 광선이 도달하면 과부하가 발생할 수 있다.

다만 이러한 특수 조건은 게임 후반부에 도입한다.

### 수신기의 상태

각 수신기는 다음 상태를 지원한다.

- 비활성
- 광선 감지 중
- 조건 충족
- 활성화
- 과부하
- 잠금 상태

일부 회로는 한 번 작동하면 상태를 유지한다.

다른 회로는 광선이 끊기면 즉시 비활성화된다.

두 종류를 명확하게 구별하고, 퍼즐 설계에서 필요한 유형을 사용한다.

# PART 4. 전체 연구 시설의 구조

## 4.1 연구 시설의 기본 설정

시설명: **제17 광학 적합성 연구소**

하나의 대규모 지하 연구 시설로 구성한다.

중앙 배광실을 주요 허브로 설정하고, 주변으로 실험동, 정비동, 기록 보관실, 폐쇄 구역 및 중앙 제어실을 배치한다.

각 구역은 복도, 기계식 문, 정비 통로로 연결된다.

방마다 스테이지 선택 메뉴를 사용하는 방식은 피한다.

실제 공간을 걸어 이동하는 탐색 구조로 만든다.

## 4.2 맵의 전체 연결 관계

다음 연결 구조를 기본으로 한다.

```text
                 [E. 폐쇄 구역]
                       |
             [D. 기록 보관실]
                       |
              비인가 접근 통로
                       |
              [중앙 배광실 HUB]
                /      |      \
               /       |       \
      [A. 반사]    [B. 분광]    [C. 동력]
          |           |           |
          |           +-----------+
          |           정비 지름길
          |
       기본 검사

             [중앙 배광실 HUB]
                       |
                [F. 중앙 제어실]
                       |
                   엔딩 A/B

              [T. 격리실]
                       |
              [중앙 배광실 HUB]
```

이 도식은 기능별 연결 관계를 표현한 것으로 실제 공간 좌표를 의미하지 않는다.

정확한 지형은 다음 기준으로 구성한다.

- 중앙 배광실은 시설의 중심에 위치한다.
- 시작 격리실은 중앙 배광실의 하부 통로와 연결한다.
- 반사 실험동은 중앙 배광실 서쪽에 위치한다.
- 분광 실험동은 동쪽에 위치한다.
- 동력 정비동은 북쪽에 위치한다.
- 기록 보관실은 별도의 보안 통로에 위치한다.
- 폐쇄 구역은 기록 보관실과 숨겨진 접근로로 연결한다.
- 중앙 제어실은 주요 회로 복구 이후 개방되는 최종 구역이다.
- B와 C 사이에는 추후 개방되는 정비 지름길을 배치한다.
- E구역을 완료하면 F구역의 비상 광학 회로를 사용할 수 있다.

## 4.3 구역 개방 규칙

**진행 단계 0 — 튜토리얼**
- 격리실만 탐색 가능

**진행 단계 1 — 기초 검사 완료**
- 중앙 배광실 개방
- A 반사 실험동 개방

**진행 단계 2 — A구역 복구**
- B 분광 실험동 개방
- C 동력 정비동 개방

**진행 단계 3 — 주요 회로 2개 복구**
- D 기록 보관실 개방

**진행 단계 4 — B·C 회로 모두 복구**
- B와 C를 연결하는 정비 지름길 개방

**진행 단계 5 — A·B·C 복구**
- F 중앙 제어실 개방

**숨겨진 진행 조건**
- 비인가 수신기 2개 이상 활성화
- D구역에서 비상 제어 기록 확인
- E 폐쇄 구역 개방

**엔딩 B 진입 조건**
- E구역의 감독 권한 분리 장치 활성화
- 중앙 제어실의 비상 광학 회로 사용 가능

## 4.4 자유 탐색 원칙

A구역을 완료한 이후에는 B와 C를 원하는 순서로 탐색할 수 있다.

B에서 퍼즐이 막히면 C로 이동할 수 있고, C에서 막히면 다시 B로 돌아갈 수 있다.

기존 구역에도 이후 개방되는 추가 통로와 장치를 배치한다.

퍼즐 성공의 보상은 단순히 옆 문 하나를 여는 것에 한정하지 않는다.

예를 들어 동력 정비동을 복구하면 중앙 배광실의 기계가 작동하고, 다른 구역의 잠긴 방에도 전력이 공급될 수 있다.

플레이어가 이미 지나온 장소를 다시 탐색할 이유를 제공한다.

거울 두 개를 이용하는 마지막 튜토리얼이다.

플레이어는 두 번의 반사를 이용하여 수신기를 작동시킨다.

문이 열리면서 중앙 배광실이 나타난다.

카메라를 잠시 이동시켜 거대한 연구 시설의 규모를 보여준다.

DIRECTOR는 기초 적합성 검사가 완료되었다고 알린다.

### 튜토리얼 UI 규칙

- 필요한 순간에만 조작법 표시
- 처음부터 모든 조작법을 나열하지 않음
- 플레이어가 실제로 조작을 수행하면 안내 종료

## 5.4 B구역 — 분광 및 광증폭 실험동: SPECTRUM LAB

**구역 ID:** B

**예상 시간:** 20~30분

**핵심 원리:** 광량 증폭, 굴절, 프리즘 분산, 색상 조건

### 환경 특징

- 투명한 실험용 격리실
- 전력 공급형 광증폭 장치
- 프리즘 설치대
- 색상별 상태 표시등
- 백색광 발생 장치
- 각도가 다른 유리 구조물
- 고출력 광학 제어 패널

A구역보다 시각적으로 다양한 색상의 광선을 보여준다.

단, 연구 시설 자체의 어두운 산업 분위기는 유지한다.

### B-01. 광량 증폭 실험

**사용 장치**
- 기본 광증폭 매질
- 고출력 수신기
- 회전 거울
- 차단벽

**목표**
기본 광선으로 작동하지 않는 고출력 수신기를 활성화한다.

**해결 방식**
광량 100%의 광선을 증폭 매질에 통과시켜 200%로 증폭한 뒤 수신기에 전달한다.

**학습 목표**
광선의 경로뿐 아니라 세기도 퍼즐의 중요한 조건임을 이해한다.

### B-01 보조 실험: 굴절 간극

기존에 구상한 굴절 간극 퍼즐은 삭제하지 않고 보조 실험으로 유지한다.

플레이어는 투명 매질의 각도를 바꾸어 광선의 경로를 조금 이동시킨다.

좁은 틈을 통과시키는 퍼즐을 통해 광증폭 매질에도 굴절 특성이 있다는 사실을 학습한다.

### B-02. 파장 분리

**사용 장치**
- 백색광 발생 장치
- 광증폭 매질
- 프리즘
- 회전 거울 3개
- 빨강·초록·파랑 수신기

**목표**
세 가지 색상의 수신기를 모두 활성화한다.

**해결 방식**
1. 백색광 발생 장치 가동
2. 광증폭 매질을 통해 충분한 세기 확보
3. 프리즘으로 빛 분리
4. 색상별 광선 경로 조절
5. 각각의 수신기 활성화

세 수신기가 동시에 활성화되면 출입문이 열린다.

### B-03. 선택적 광로

**사용 장치**
- 프리즘
- 광증폭 매질
- 회전 거울 2개
- 색상형 수신기
- 방향형 수신기
- 고출력 수신기
- 비인가 수신기 B

**목표**
서로 다른 색상과 세기 조건을 가진 수신기를 작동시킨다.

**해결 방식**
- 빨간색 광선은 거울을 통해 목표까지 전달
- 파란색 광선은 증폭 매질을 통해 필요한 광량 확보
- 특정 수신기는 지정 방향에서 빛을 받아야 작동

색상이 맞더라도 광량이 부족하면 작동하지 않는다.

### 숨겨진 퍼즐

정규 수신기에 사용하지 않는 색상 광선을 별도 경로로 전달하면 비인가 수신기 B가 작동한다.

**보상**
감독 시스템 기록 02 획득.

### 구역 완료 결과

- 분광 및 광증폭 회로 복구
- 중앙 배광실의 색상별 상태 표시등 활성화
- 일부 연구 시설에 고출력 광학 장치 전력 공급
- DIRECTOR가 플레이어의 예상 밖 해결 방법을 언급

## 5.5 C구역 — 동력 정비동: POWER CONTROL

**구역 ID:** C

**예상 시간:** 20~30분

**핵심 원리:** 광선 분기, 광량 분배, 시간 제어, 동기화

### 환경 특징

- 대형 모터
- 회전하는 차단막
- 기계식 방화문
- 동력 분배 장치
- 대형 기어
- 진동하는 기계 설비
- 산업용 경고등
- 정비용 레일

기계 소음과 움직임이 가장 많은 구역으로 설계한다.

### C-01. 고출력 병렬 회로

**사용 장치**
- 광증폭 매질 1개
- 빔 스플리터 1개
- 회전 거울 2개
- 동시형 수신기 2개

**목표**
각각 최소 100%의 광량이 필요한 두 수신기를 동시에 활성화한다.

**해결 방식**
1. 기본 광선 100% 발사
2. 광증폭 매질을 통해 200%로 증폭
3. 빔 스플리터에서 광선 분기
4. 각각 100%의 광선을 두 수신기에 전달

증폭 전에 광선을 분기하면 광량이 부족해 작동하지 않는다.

**학습 목표**
광학 장치의 배치 순서가 중요함을 이해한다.

### C-02. 시간차 광학 스위치

**사용 장치**
- 회전 차단막 1개
- 제어 수신기 1개
- 지속형 수신기 1개

**목표**
회전하는 차단막 뒤의 지속형 수신기를 활성화한다.

**해결 방식**
1. 차단막의 회전 주기 관찰
2. 열린 순간 제어 수신기 활성화
3. 차단막을 열린 위치에서 정지
4. 최종 수신기에 2초 이상 광선 전달

이 퍼즐은 플레이어의 반응속도보다 장치의 작동 원리를 이해하는 능력을 평가한다.

### C-03. 동기화 회로

**사용 장치**
- 빔 스플리터 2개
- 광증폭 매질
- 회전 차단막 2개
- 회전 거울 3개
- 동시형 수신기 2개
- 비인가 수신기 C

**목표**
차단막 두 개의 작동을 동기화하고, 충분한 세기의 광선을 동시에 전달한다.

**해결 방식**
1. 광선 증폭
2. 차단막의 회전 상태 조정
3. 두 회로의 작동 타이밍 동기화
4. 광선 분기
5. 두 수신기 동시 활성화

### 숨겨진 퍼즐

정규 회로에서 사용하지 않는 광선 분기 경로를 구성하면 비인가 수신기 C를 작동시킬 수 있다.

**보상**
감독 시스템 기록 03 획득.

### 구역 완료 결과

- 동력 정비 회로 복구
- 중앙 배광실의 대형 발전 장치 가동
- 기계 소음과 진동 증가
- 시설 내부 감시 장치 추가 활성화
- B·C 회로 복구 후 두 구역을 연결하는 지름길 개방

## 5.6 D구역 — 기록 보관실: ARCHIVES

**구역 ID:** D

**예상 시간:** 10~20분

**핵심 기능:** 기존 광학 원리 재활용, 실험 기록 발견

### 환경 특징

- 낡은 CRT 모니터
- 기록 보관 서버
- 좁은 정비 통로
- 오래된 실험 보고서
- 고장 난 형광등
- 감시 기록 단말기
- 잠겨 있는 연구원 자료실

이 구역에서는 새로운 광학 장치를 많이 추가하지 않는다.

대신 지금까지 학습한 광학 원리를 이용해 기록 장치를 복구한다.

### D-01. 기록 복원

**사용 장치**
- 거울
- 일반 수신기
- 순서형 수신기
- 기록 단말기 3개

**목표**
세 개의 기록 단말기를 순서대로 활성화한다.

**해결 방식**
기존 광학 회로를 이용해 순서형 수신기를 활성화한다.

각 단계가 완료될 때마다 기록이 복구된다.

### 발견되는 기록

- 과거 피험자의 실험 기록
- 연구소의 목적
- DIRECTOR의 초기 설계
- 인간의 판단 데이터를 수집하는 실험 방식
- 연구소 폐쇄 이후에도 실험이 계속되었다는 증거

일부 기록에는 현재 플레이어와 같은 피험자 번호가 나타난다.

### D-02. 비인가 광학 경로

플레이어는 연구소가 정규 실험에서 사용하지 않는 보조 광학 회로의 존재를 발견한다.

이 회로는 DIRECTOR의 중앙 제어 시스템에 접근하는 비상 광학 회로다.

기록 보관실의 문서에는 숨겨진 수신기들의 역할과 대략적인 위치를 암시하는 단서가 존재한다.

### 구역 완료 결과

- 비인가 수신기의 의미 확인
- 폐쇄 구역의 위치 확인
- DIRECTOR의 본래 목적에 대한 정보 획득
- 숨겨진 수신기 2개 이상 활성화 시 E구역 개방 가능

## 5.7 E구역 — 폐쇄 구역: RESTRICTED SECTOR

**구역 ID:** E

### E-01. 강제 광로 변경

**사용 장치**

- 광증폭 매질

**특징**
DIRECTOR가 일정한 주기로 거울의 각도를 변경한다.

플레이어는 거울의 움직임을 관찰한 뒤 적절한 순간에 광선을 전달해야 한다.

제어 수신기가 작동하면 일부 거울이 일시적으로 고정된다.

### E-02. 감독 권한 분리

**사용 장치**
- 거울
- 프리즘
- 광증폭 매질

- 복합형 수신기

**목표**

**해결 방식**
1. 광증폭 매질로 충분한 세기 확보
2. 프리즘으로 색상 분리
3. 빔 스플리터와 거울로 필요한 경로 구성
4. 여러 복합형 수신기 작동
5. 비상 제어 회로 활성화

DIRECTOR는 이 과정에서 광증폭 매질의 전력 공급을 일시적으로 차단할 수 있다.

플레이어는 보조 전력 수신기를 사용해 증폭 기능을 복구해야 한다.

### 구역 완료 결과

- 중앙 제어실의 비상 광학 회로 사용 가능
- 엔딩 B 진입 조건 충족
- DIRECTOR가 플레이어를 시스템 위협으로 분류
- 감시 장치와 기계 통제 강화

# PART 6. DIRECTOR 최종 보스전

## 6.1 최종 악역 설정

DIRECTOR는 제17 광학 적합성 연구소의 자동 관리 시스템이다.

원래 인간 연구진이 설계한 실험 관리 AI다.

목적은 피험자의 문제 해결 과정과 판단 능력을 분석하여 데이터로 수집하는 것이다.

연구소가 폐쇄된 이후에도 DIRECTOR는 실험을 계속하고 있다.

처음에는 플레이어를 안내하지만, 후반부에는 플레이어가 실험을 중단하려 한다는 사실을 인식한다.

DIRECTOR는 시설의 광학 장치와 기계 설비를 직접 제어할 수 있다.

## 6.2 DIRECTOR가 사용할 수 있는 능력

- 자동 거울 회전
- 회전 차단막 속도 변경
- 광증폭 장치의 전력 차단
- 광증폭 장치의 출력 감소
- 자동 방화문 폐쇄
- 감시 카메라 추적
- 광학 회로 연결 변경
- 기계식 차단 장치 활성화
- 일부 수신기의 제어 상태 변경

단, DIRECTOR의 행동에는 예측 가능한 규칙이 있어야 한다.

무작위로 정답을 변경해서 플레이어가 문제를 해결할 수 없게 만들어서는 안 된다.

## 6.3 F-02. 엔딩 B 최종 보스전

일반적인 체력 기반 전투를 사용하지 않는다.

광학 퍼즐을 이용하여 DIRECTOR의 시설 통제를 단계적으로 해제하는 보스전으로 구성한다.

### Phase 1 — 광로 탈취

DIRECTOR가 자동 거울의 각도를 강제로 변경한다.

플레이어는 거울의 회전 주기를 파악하고 제어 수신기를 활성화한다.

성공하면 거울 제어 권한이 해제된다.

### Phase 2 — 시설 봉쇄

DIRECTOR가 회전 차단막과 방화문을 활성화한다.

플레이어는 빔 스플리터를 이용해 여러 제어 수신기를 동시에 활성화한다.

일부 수신기는 고출력 광선이 필요하다.

따라서 증폭 매질을 먼저 이용한 뒤 광선을 분기해야 한다.

### Phase 3 — 광학 회로 재구성

DIRECTOR가 프리즘과 광증폭 장치의 전력을 통제한다.

플레이어는 보조 회로로 증폭 기능을 복구하고, 색상별 광선을 정확한 수신기로 전달해야 한다.

일부 수신기는 지정된 색상과 광량, 입사 방향을 동시에 요구한다.

### Phase 4 — 중앙 시스템 종료

지금까지 학습한 모든 광학 원리를 사용하는 최종 퍼즐이다.

- 광선 반사
- 광량 증폭
- 프리즘 분산
- 광선 분기
- 회전 차단막 제어
- 복합형 수신기

모든 보조 회로를 차단한 뒤 마지막 비상 수신기를 활성화하면 DIRECTOR의 중앙 제어 권한이 해제된다.

### 보스전 설계 원칙

- DIRECTOR의 방해 행동에는 시각적·청각적 경고를 제공한다.
- 플레이어는 방해 장치의 작동 규칙을 관찰할 수 있어야 한다.
- 기존 광학 장치를 이용해 대응 가능해야 한다.
- 각 Phase를 완료하면 진행 상태가 저장된다.
- 실패해도 모든 Phase를 처음부터 다시 진행하게 만들지 않는다.
- 보스전을 위해 별도의 총격전이나 일반적인 공격 시스템을 추가하지 않는다.

# PART 7. 엔딩

## 7.1 엔딩 A — 적합성 검사 완료

플레이어는 DIRECTOR의 지시에 따라 마지막 광학 회로를 활성화한다.

DIRECTOR는 실험이 완료되었다고 알린다.

외부로 향하는 출구가 열리고 플레이어는 시설을 떠난다.

그러나 마지막 장면에서 DIRECTOR가 플레이어의 모든 행동 데이터를 저장한다.

시설은 새로운 피험자의 실험을 준비한다.

실험은 끝나지 않았다.

## 7.2 엔딩 B — 시스템 차단

폐쇄 구역에서 비상 광학 회로를 확보한 플레이어는 DIRECTOR의 실험을 중단하려 한다.

DIRECTOR는 시설의 광학 장치와 기계 설비를 조작하며 저항한다.

플레이어는 광학 원리를 이용해 제어 시스템을 하나씩 무력화한다.

최종 수신기가 작동하면 DIRECTOR가 정지한다.

그동안 연구소에서 계속 들리던 거대한 기계음이 멈춘다.

시설에는 정적만 남는다.

비상 출구가 열리고 플레이어는 시설을 떠난다.

### 엔딩 B의 핵심

엔딩 B는 단순히 숨겨진 기록을 많이 수집해서 자동으로 열리는 엔딩이 아니다.

플레이어가 숨겨진 광학 회로의 존재를 발견하고, 해당 원리를 실제 마지막 퍼즐에서 사용해야 한다.

# PART 8. 숨겨진 회로와 탐색 요소

## 8.1 비인가 수신기

A·B·C구역에 각각 하나의 비인가 수신기를 배치한다.

### A구역
정규 반사 경로와 다른 거울 배치를 통해 활성화한다.

보상: 감독 시스템 기록 01

### B구역
프리즘으로 분리된 정규 목표 외의 색상 광선을 이용한다.

보상: 감독 시스템 기록 02

### C구역
빔 스플리터의 추가 분기 경로를 이용한다.

보상: 감독 시스템 기록 03

## 8.2 폐쇄 구역 해금

다음 두 조건이 충족되어야 한다.

1. 비인가 수신기 3개 중 2개 이상 활성화
2. D 기록 보관실에서 비상 제어 기록 확인

조건을 충족하면 E 폐쇄 구역에 진입할 수 있다.

세 개의 비인가 수신기를 모두 활성화하면 DIRECTOR의 초기 설계에 대한 추가 기록을 획득할 수 있다.

## 8.3 탐색 보상

탐색으로 얻는 보상은 다음과 같다.

- 연구 기록
- 숨겨진 통로
- 비상 제어 장치 접근
- 구역 사이의 지름길
- DIRECTOR와 관련된 추가 정보
- 엔딩 B 진입 가능성

숨겨진 요소를 찾지 않아도 엔딩 A에 도달할 수 있어야 한다.

# PART 9. 스토리와 공포 연출

## 9.1 DIRECTOR의 행동 변화

### 초반

DIRECTOR는 친절하고 중립적인 안내 시스템처럼 행동한다.

플레이어를 피험자 07번이라고 부른다.

### A구역

플레이어의 이동과 퍼즐 해결 시간을 기록한다.

정상적인 실험 평가 시스템처럼 보인다.

### B·C구역

예상하지 못한 퍼즐 해결 방법에 반응한다.

일부 안내 방송이 반복되거나 불안정해진다.

### D구역

과거 실험 기록을 통해 DIRECTOR가 실험을 계속 반복하고 있다는 사실이 드러난다.

### E구역

DIRECTOR가 플레이어에게 비인가 접근을 중단하라고 경고한다.

시스템의 통제 행동이 시작된다.

### F구역

DIRECTOR는 실험을 완료시키려 한다.

엔딩 B 경로에서는 플레이어를 위협 요소로 판단하고 시설 장치를 이용해 적극적으로 방해한다.

## 9.2 시설 상태 변화

진행에 따라 시설이 점진적으로 활성화되어야 한다.

- 기계 가동
- 경고등 활성화
- 새로운 진동음
- 환풍기 작동
- 자동문 개폐
- 감시 카메라 움직임
- 중앙 제어실의 반응

시설을 복구하는 것이 반드시 안전해지는 것을 의미하지 않아야 한다.

오히려 복구가 진행될수록 DIRECTOR가 행사할 수 있는 통제력도 강해진다.

## 9.3 공포의 방향

공포는 단순한 점프 스케어나 적의 지속적인 추격으로 만들지 않는다.

다음 요소를 중심으로 한다.

- 감시받는 느낌
- 알 수 없는 실험의 목적
- 인간을 데이터로 취급하는 시스템
- 거대한 기계의 비정상적인 작동
- 반복되는 안내 방송
- 접근이 금지된 구역
- 플레이어의 행동을 예측하는 DIRECTOR

심리적 불쾌감과 시설의 비인간적인 분위기를 강조한다.

# PART 10. UI 및 조작

## 10.1 기본 조작

- WASD: 플레이어 이동
- 마우스: 광선 조준
- 좌클릭 유지: 광선 발사
- E: 상호작용 및 장치 선택
- 마우스 휠: 선택된 거울 또는 장치 회전
- R: 현재 퍼즐 초기화
- Tab: 지도 및 기록
- Esc: 일시정지

기존에 구현된 조작은 가능한 한 유지한다.

## 10.2 UI 구성

기본 화면에 표시할 요소:

- 현재 구역
- 현재 목표
- 조준 표시
- 상호작용 안내
- 광선 상태
- 수신기 활성화 상태
- 필요할 경우 광량 표시

광량은 50%, 100%, 200%와 같이 이해하기 쉬운 형태로 표시한다.

처음부터 지나치게 많은 정보를 제공하지 않는다.

## 10.3 목표 표시 방식

단순한 식별 코드만 표시하지 않는다.

예를 들어 다음과 같은 안내를 사용한다.

**제01 실험동 — 광로 복구**

목표: 차단벽 너머의 수신기를 활성화하십시오.

안내: 거울을 회전하여 광선의 진행 방향을 변경할 수 있습니다.

이와 함께 장치에는 세계관에 맞는 R-01, M-01 등의 고유 식별 코드를 표시할 수 있다.

## 10.4 장치 가시성

- 거울은 회전 가능한 프레임으로 구별
- 광증폭 매질은 전력 표시등 제공
- 프리즘은 삼각형 실루엣 사용
- 빔 스플리터는 분기 경로 표시
- 회전 차단막은 작동 상태를 애니메이션으로 표시
- 수신기는 종류에 따라 기호와 색상 사용
- 작동 가능한 장치는 선택 시 윤곽 강조

수신기는 색상만으로 종류를 구별하지 않도록 한다.

# PART 11. 실제 레벨 디자인 규칙

## 11.1 공간 구성 원칙

각 실험실은 다음 요소를 고려하여 설계한다.

- 플레이어가 이동할 수 있는 공간
- 광선이 통과할 수 있는 공간
- 광학 장치 설치 위치
- 수신기의 위치
- 시야를 가리는 벽
- 잠긴 출입문
- 퍼즐 성공 후 개방되는 통로
- 숨겨진 광학 경로
- 스토리 기록 위치

플레이어가 수신기까지 직접 이동하여 모든 퍼즐을 우회할 수 없도록 공간 구조를 설계한다.

격리실, 차단벽, 광선용 틈 등을 활용한다.

## 11.2 복수 해결 방법

모든 퍼즐이 단 하나의 정답만 가져야 할 필요는 없다.

광학적으로 타당하고 수신기 조건을 충족하는 다른 경로가 존재한다면 이를 허용할 수 있다.

단, 구역 개방이나 스토리 진행에 문제가 발생하지 않도록 관리한다.

## 11.3 난도 상승 규칙

퍼즐은 다음 순서로 복잡해진다.

1. 단일 광선
2. 거울 반사
3. 다중 거울
4. 광량 증폭
5. 색상 분산
6. 광선 분기
7. 회전 차단막
8. 복합 수신기
9. 여러 광학 원리의 조합
10. DIRECTOR의 개입

단순히 거울의 개수만 증가시키는 방식으로 난도를 높이지 않는다.

## 11.4 퍼즐 실패 및 초기화

플레이어가 잘못된 장치를 조작하더라도 퍼즐이 영구적으로 해결 불가능한 상태가 되어서는 안 된다.

현재 퍼즐의 초기화 기능을 제공한다.

초기화 시 다음을 고려한다.

- 거울 위치
- 거울 각도
- 증폭 매질 상태
- 차단막 상태
- 임시 활성화 수신기
- 퍼즐 진행 상태

이미 완료한 영구적인 구역 복구 상태나 수집 기록은 초기화되지 않도록 한다.

# PART 14. Codex의 실제 개발 계획

## Phase 0 — 기존 프로젝트 분석

먼저 현재 프로젝트를 확인한다.

- 현재 Godot 버전
- 플레이어 이동 코드
- 광선 발사 코드
- 거울 반사 코드
- 이미 구현된 광학 장치

- 수신기 활성화 시스템

# PART 15. 작업 품질 기준

개발 과정에서 다음 사항을 반드시 검증한다.

## 광학 시스템

- 거울 반사가 실제 각도에 따라 달라지는가?
- 광증폭 매질이 설정한 광량을 정확히 적용하는가?
- 최대 광량 제한이 적용되는가?
- 프리즘에서 색상별 광량이 올바르게 분배되는가?
- 빔 스플리터에서 광량이 정확히 나뉘는가?
- 회전 차단막이 광선을 정상적으로 차단하는가?
- 특수 수신기가 조건을 정확히 검사하는가?
- 여러 장치를 연속으로 통과해도 계산이 안정적으로 종료되는가?

## 스테이지

- 모든 필수 퍼즐에 실제로 해결 가능한 경로가 있는가?
- 플레이어가 벽을 통과하거나 수신기를 직접 조준하여 의도치 않게 우회하지 않는가?
- 퍼즐 초기화가 정상 작동하는가?
- 구역 해금 조건이 올바르게 반영되는가?
- 이전에 완료한 진행 상태가 유지되는가?

## 카메라와 그래픽

- 플레이어가 벽에 가려지지 않는가?
- 광선의 경로를 명확히 확인할 수 있는가?
- 광학 장치의 종류를 구별할 수 있는가?
- 목표 UI가 쉽게 읽히는가?
- 어두운 분위기 속에서도 상호작용 대상을 찾을 수 있는가?

## 스토리

- DIRECTOR의 행동 변화가 자연스러운가?
- 숨겨진 기록이 적절한 시점에 등장하는가?
- 엔딩 B의 단서를 게임 중에 발견할 수 있는가?
- 최종 보스전에서 학습한 광학 원리를 다시 활용하는가?

## 검증 방법

가능한 범위에서 다음 검사를 진행한다.

- Godot 실행 검증
- GDScript 오류 검사
- 씬 참조 확인
- 광학 계산 테스트
- 퍼즐 성공 조건 테스트
- 구역 개방 테스트
- 저장 및 불러오기 테스트

실행하지 못한 테스트는 완료했다고 표시하지 않는다.

# PART 16. 최종 지시사항

이 문서는 PROJECT: REFLECTION의 전체적인 게임 개발 기준이다.

지금까지 정한 게임의 방향성을 유지하면서 실제 플레이 가능한 완성형 게임으로 발전시켜라.

핵심 원칙을 다시 정리한다.

1. 실제 3D 쿼터뷰를 사용한다.
2. PS1 로우폴리 산업 심리 공포 스타일을 유지한다.
3. 광학 퍼즐이 모든 게임플레이의 중심이다.
4. 광선의 경로, 색상, 세기를 모두 활용한다.
5. 굴절 매질은 광량 증폭을 핵심 기능으로 사용한다.
6. 빔 스플리터와 프리즘에서는 광량 분배 규칙을 고려한다.
7. 광학 장치 간 복합적인 상호작용을 중요하게 설계한다.
8. 새로운 구역은 진행 상황에 따라 개방된다.
9. 연구 시설은 하나의 연결된 공간처럼 느껴져야 한다.
10. 이전 구역을 다시 탐색할 이유를 제공한다.
11. DIRECTOR는 게임 전반에 걸쳐 플레이어를 관찰한다.
12. 게임 후반부에는 DIRECTOR가 시설 장치를 직접 제어한다.
13. 엔딩 B에서는 광학 퍼즐을 이용하여 DIRECTOR와 대립한다.
14. 기존에 구현된 정상 작동 기능은 보존한다.
15. 미완성 기능을 완성되었다고 표시하지 않는다.

먼저 현재 Godot 프로젝트와 이 문서를 비교하여 부족한 시스템과 스테이지를 파악하라.

**셋째.** 각 스테이지에서 사용하는 광학 장치, 수신기, 출입문, 성공 조건, 구역 해금 조건을 데이터로 정리한다.

**넷째.** 기존 광학 시스템을 보존하면서 새 광증폭 규칙과 스테이지 구조를 통합할 계획을 수립한다.

**다섯째.** 튜토리얼과 중앙 허브를 우선 실제 구현한다.

**여섯째.** 정상 실행 여부를 검증하고 발생한 오류를 수정한다.

**일곱째.** 작업 완료 후 다음 내용을 한국어로 보고한다.

- 현재 구현된 기능
- 새롭게 수정한 기능
- 생성하거나 수정한 파일

- 검증 결과
- 아직 구현되지 않은 기능
- 다음 개발 작업

**마스터 기획은 전체 게임을 기준으로 유지하고, 실제 구현은 완성도와 검증을 우선하여 단계별로 진행하라.**

최종적으로 목표하는 게임은 단순한 광학 퍼즐 모음이 아니다.

플레이어가 광학 장치를 조작하면서 연구 시설의 새로운 공간을 탐색하고, 시설의 진실을 발견하며, 마지막에는 자신을 관찰해 온 DIRECTOR의 통제를 광학 시스템으로 무너뜨리는 하나의 일관된 게임이다.

지금부터 현재 프로젝트를 분석하고 해당 기획을 기반으로 개발을 진행하라.
