03  최근 확정 변경 사항 — 기존 문서보다 우선
03.1  A-01 광학 제어 콘솔
E로 콘솔 진입 시 별도 모드 전환 없이 즉시 광학 제어 상태가 됩니다.
마우스 좌클릭: 거울 선택. 마우스 휠: 선택한 거울 회전. Shift + 휠: 정밀 회전. Esc: 조작 종료.
선택 거울의 식별 및 각도를 UI에 표시하고, 선택 해제·재선택 과정은 직관적으로 구현하세요.
이동·일반 광선 발사는 콘솔 조작 중 정지되거나 안전하게 제한되어야 하며, 종료 시 정상 플레이 카메라·조작으로 복귀해야 합니다.
V 키를 눌러 광학 조작 모드를 별도로 전환하는 옛 조작 방식은 다시 도입하지 마세요.
03.2  A-02 발사기 거치 시스템
A-02의 레일형 거울은 정확히 1개입니다(기존 v6.2 장치 개수 보존).
일반 거울은 먼저 광학 제어 콘솔에서 설정합니다.
플레이어는 휴대용 광선 발사기를 거치대에 장착해 지속 조사하도록 만들고, 이후 현장으로 이동해 레일 거울을 직접 옮겨 최종 광선 경로를 완성합니다.
제어 수신기에 의한 레일 잠금 해제 조건과 최종 수신기 활성화 조건을 구분하세요.
발사기 탈착, 광선 유지/중지, 레일 이동 한계, 리셋/재시도, 플레이어 장비 상태가 모순 없이 동작해야 합니다.
03.3  광학 매질의 역할
굴절률 n을 숫자로 보여주거나 직접 조절하는 퍼즐로 바꾸지 마세요.
광증폭 굴절 매질은 외부 전력으로 빛의 세기를 자동 증가시키는 장치이며, 굴절은 보조적인 경로 변화 효과일 수 있습니다.
증폭 배율을 플레이어가 임의로 조절하는 기능은 추가하지 마세요.

07  시설 공간·아트·스토리 구현 방향
건물은 사용하지 않는 빈 띠·막다른 복도·불필요한 경비실/보관실을 줄이고, 공유 벽은 단일 벽으로 구현합니다.
모든 실제 이동 통로는 물리적인 문 개구부 및 충돌체와 일치해야 합니다. 미방문 구역 내부 지도는 숨깁니다.
공포는 조명, 산업 시설 소리, 불안한 로그, 비정상 안내, 부분적인 환경 변화로 조성합니다.
DIRECTOR는 관찰·안내·상태 관리의 역할이며 광학 장치를 원격으로 임의 조작하거나 전투 보스로 등장하지 않습니다.
확정되지 않은 피험자 07의 실체·추가 엔딩의 줄거리 등을 게임의 공식 정답으로 일방적으로 결정하지 마세요.

완료된 기능, 수정 파일 목록, 실행 명령, 남은 버그와 미확정 디자인 항목을 README 또는 docs/ 진행 문서에 기록하세요.
