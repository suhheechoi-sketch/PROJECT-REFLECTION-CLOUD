## 구현한 기능

- 기존 ReflectionPlayer, CameraPointer, OpticalDevice, ReflectionLaser 및 장치 외장·재질 생성기를 공유한다. 광선 추적기는 수정하지 않았다. 반사는 실제 충돌 면의 법선에서 계산하며 정답 버튼·도달 트리거로 퍼즐을 통과시키지 않는다.
- 방 14개(방/복도 포함)와 9개 조건부 문. 닫힌 문·벽은 플레이어/빛을 차단하고 0.5m 광학 창은 몸만 차단한다. 접근이 어려웠던 통로는 충돌 검사를 기준으로 수정했다. [최종 좌표](TA_DEMO_VALIDATED_GEOMETRY.md).
- T01 이동 2m 및 신원 E, T02 지급대 E와 직사, T03 한 거울, T04 두 거울과 종료 단말기 E. 각 단계가 다음 방문 경로를 연다.
- A01 콘솔 E 즉시 조작, 클릭 선택·해제·재선택, 휠 15°/Shift+휠 1°, 선택 이름/각도 표시, Esc 복귀. 세 거울 모두 물리적으로 필요하다.
- A02는 기존 `a02_lab.gd` 재사용. L-07 소유권을 거치대로 이전하고 휴대 광선은 정지한다. E 탈착, F 정지/재개, 제어 R 0.7초, 현장 손잡이 E와 0.25m 이동, 4m 한계, 최종 R 1.2초. 남아 있던 레일 선택이 다른 방의 휠을 가로채는 문제도 수정했다.
- A03 일반 거울 4개·고정 각도 레일 거울 1개. 각 수신기의 실제 조사 후 순서를 검사한다. 잘못된 순서와 이미 승인한 이전 수신기를 다시 쏘는 경우 순서만 초기화한다. R-U는 선택 스토리다. 마지막 RN은 READY만 만든다.
- A 복구실의 기록과 DIRECTOR가 피험자 07 입장 기록의 모순을 암시한다. 복구 E 후 기존 진행 상태에도 A RESTORED를 기록하고 약 3초의 이상 현상·페이드 뒤 DEMO END. 후반 스토리를 완결하지 않는다.
- R: 미완료 현재 퍼즐 재시도, 완료 단계 보존. Shift+R: 모든 데모 진행/장비 초기화. 완료 단계·광원 소유·탐색 셀을 원자적 체크포인트 파일로 저장. 재시작 시 미완료 퍼즐 입구에서 안전하게 재개한다. 미완료 각도/부분 조사/순서 단계는 저장하지 않는다. 종료 후 재시작은 종료 화면 유지.
- H/F1 도움말, L 기록, M 미니맵, Tab 탐색 지도(기존 ExplorationMapView 재사용), Esc 일시 정지, 수신기 링·문 잠금/해금·거치 상태·순서/목표 HUD. 미탐색 셀은 지도에 싣지 않는다.
- PS1 디더링/6비트 색·64px 표면, T/A 팔레트 분리, 침상·감시 카메라·CRT 단말기·경고 표식·배관·케이블·부분 전등 변동. 자체 생성 기계음·수신 성공음 포함. 외부 아트/음원을 가져오지 않았다.

## 미검증·남은 요소

- **수동 첫 시작→종료 완주**, 실제 마우스/키보드 감각·혼동 여부·게임패드/해상도별 UI·Windows 실행은 미검증이다.
- 실제 오디오 장치 청취, 장시간 성능/메모리 측정, 2~3분 시연 영상 촬영은 미수행이다. [촬영 경로](TA_DEMO_CAPTURE_ROUTE.md)는 편집 구성안이다.
- 모든 연속 위치/각도의 우회 가능성을 증명한 것은 아니다. 자동 도달성/직사격 검사는 0.5m 샘플과 지정 경로를 대상으로 한다.
- 아트는 이번 절차형 데모 수준이다. 전문 모델링·최종 사운드 믹스·수작업 환경 디테일까지 완성한 빌드로 표시하지 않는다.
- 진행 체크포인트는 완료 단계 단위다. 미완료 퍼즐의 각도·부분 타이머·정확한 서 있는 위치를 복원하는 전체 세이브는 제공하지 않는다.
- 렌더링 종료 시 WAV 정리 경고가 남는다. headless 검사에서는 오디오 생성을 건너뛰어 경고가 없다.
- B~F/H는 이번 데모에서 접근하지 않는다. 기존 전체 시설 씬과 소스는 보존했으며 해당 구역의 완성을 주장하지 않는다. 잠긴 자산은 보존했다. `v3-before-v4-quality` 태그는 로컬과 원격 태그 fetch 후에도 발견되지 않아 존재한다고 주장하지 않으며 새로 만들지 않았다.
