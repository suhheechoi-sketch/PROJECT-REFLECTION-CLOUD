# A-01 광학 제어 v2

## 조작 흐름

- 처음에는 A-01 기존 광학 콘솔 가까이에서 E를 눌러 연결한다. E 입력 한 번으로 권한을 저장하고 조작 모드와 퍼즐 전체 보기 카메라에 바로 들어간다.
- 연결한 뒤에는 다시 콘솔 가까이에서 E를 눌러 조작 모드에 진입한다. A-01 방 안에서만 권한을 쓸 수 있다.
- M1/M2/M3를 클릭해 선택한다. 선택한 거울을 다시 클릭하거나 빈 곳을 클릭하면 선택을 해제한다. 휠은 15도, Shift+휠은 기존 정밀 각도 단위로 회전한다.
- 조작 중 WASD와 휴대용 발사는 멈춘다. Esc는 거울 선택 여부와 관계없이 조작을 종료하고 진입 전 V 전체 보기 상태를 복원한다. 종료 직전 눌린 좌클릭은 놓을 때까지 발사로 전환되지 않는다.
- 조작 모드 밖에서는 기존 WASD, 마우스 조준/좌클릭 발사, E 상호작용, V 전체 보기, R 퍼즐 초기화가 유지된다.

## 구현 범위

- A-01의 기존 콘솔 노드와 충돌체를 재사용했다. 새 광원이나 퍼즐 장치, 충돌 판정은 추가하지 않았다.
- `control_mode` 상태가 원격 클릭·회전과 플레이어 입력을 분기한다. 화면상 UI 패널과 지도 위 클릭/휠은 장치 입력으로 전달하지 않는다. 장치 선택은 기존 카메라 투영과 물리 레이, A-01 거울 명시 목록으로 한정한다.
- 카메라 제어는 기존 `puzzle_camera.gd`를 재사용한다. 조작 모드 진입 때 전체 보기로 부드럽게 이동하고, 종료 때 이전 overview/manual-explore 상태를 복원한다. V는 일반 모드에서 기존대로 동작한다.
- 모드 진입/종료 중 플레이어 좌표, 광선 원점, 반사 계산은 변경하지 않는다.

## 자동 검증 결과

Godot 4.7.2 Compatibility에서 `VERIFY_REFLECTION.ps1` 전체 16개 검증 묶음을 실행했다. A-01 원격 제어 테스트는 헤드리스 및 NVIDIA OpenGL Compatibility 창 실행에서 모두 실패 0건으로 완료했다.

테스트는 콘솔에서 즉시 모드 진입, 세 거울 개별 선택과 회전, E 비선택, 빈 곳/선택 거울 클릭 해제, HUD·Tab 지도 클릭 차단, 다른 장치 선택 거부, WASD/발사 억제, Esc 카메라 복원, 일반 모드 V·발사 복구, R 초기화와 권한 유지, 플레이어 위치에서 시작하는 기존 3회 반사 해를 확인한다. 실제 렌더 결과는 `artifacts/remote_hover_m2.png`와 `artifacts/remote_solution.png`에서 확인했다.

실제 사람이 조작하는 장시간 플레이 테스트, 여러 화면 배율/입력 장치 조합, A-01 외 콘솔은 검증 범위에 포함하지 않았다. 프로젝트 내 다른 퍼즐의 실제 플레이 검증도 별도 수행하지 않았다.
