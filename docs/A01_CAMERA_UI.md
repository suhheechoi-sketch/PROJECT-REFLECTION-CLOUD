# A-01 카메라·UI 개선

2026-10-25 / Godot 4.7.2 Compatibility. 복구 커밋 `63c0558`에 작업 전 플레이 가능한 A-01 상태를 보존했다.

## 사용법과 결과

- 일반 탐색: 기존 플레이어 자식 직교 카메라와 하향 70°를 유지한다. size는 15.5에서 17로 약 10% 넓혔다.
- A-01 안에서 **V**: 퍼즐 전체 보기 ↔ 일반 탐색. 방 밖에서는 원격 방을 보여주지 않는다.
- 세 거울 중 하나를 E로 선택하면 선택 거울만 확대하지 않고 A-01의 세 거울·수신기·광로·플레이어를 함께 담는다. E 해제 시 추적으로 돌아간다. 선택 중에도 V를 두 번 눌러 명시적으로 탐색으로 돌아갈 수 있다. 다음 장치 선택 때 자동 구도를 다시 적용한다.
- 좌측 상단: 현재 구역·보기 모드, 간단한 목표, A/B/C 상태. **상세 ▾**를 클릭하면 기존 목표·길 안내·목적지 선택·상태 메시지를 펼치고 다시 접을 수 있다.
- 하단의 전체 조작 안내는 튜토리얼 중 또는 H/F1 도움말 요청 때만 표시한다. 거울 선택 중에는 우측 하단의 작은 카드로 장치 이름·각도·E/휠/Shift+휠/V 조작을 표시한다.
- 전체 보기/거울 조작 구도에서 M1·M2·M3·R-A01의 화면 표식을 표시한다. 표식은 입력을 가로채지 않는다.

기존 키를 조사한 결과 V 사용은 없었다. WASD, E, 휠, Shift+휠, R, Shift+R, M, Tab, H/F1, 1/2, L, Esc를 변경하지 않았다. 접기 버튼은 키보드 포커스를 받지 않아 이동 입력을 방해하지 않는다.

## 구현 방법

`puzzle_camera.gd`가 기존 Camera3D의 위치와 size를 물리 틱에서 한 번만 갱신한다. 카메라를 새로 만들거나 플레이어/카메라 계층을 교체하지 않는다. 기존 엔진 물리 보간을 유지하고 렌더 프레임에서 카메라 변환을 다시 보간하는 코드는 추가하지 않았다. 프레임 간 전환에는 시간 기반 지수 보간을 사용한다. 방 중심 모드에서는 부모 플레이어의 이동량을 보상해 플레이어 이동이 전체 보기 구도를 끌고 가지 않게 한다. 회전은 고정이다.

전체 보기 범위는 현재 A-01의 기존 방 외곽과 점검/발사 위치를 포함한 XZ 사각형, 높이 0–3.2m다. 이를 카메라의 right/up 축으로 투영해 범위를 구하고, 실제 직교 투영 배율과 뷰포트 크기에서 필요한 size를 계산한다. HUD·미니맵·선택 카드의 실제 영역을 빼고 남은 화면의 중앙에 구도를 맞춘다. 화면 비율이나 상세 UI 크기가 바뀌면 자동으로 다시 계산한다. 다른 퍼즐실을 추정해 무조건 확대하지 않는다. 이번 V 전체 보기 대상은 A-01이다.

확대해 다른 미방문 공간을 드러내지 않도록 전체 보기/선택 구도와 복귀 전환 동안 별도의 **시각 레이어**로 A-01을 표시한다. A-01 소유 메시와 방 안에 완전히 포함된 기존 소품 메시만 추가 표시하며, 다른 방까지 걸치는 큰 슬래브는 포함하지 않는다. 기존 충돌 소품이 보이지 않는 장애물이 되지 않도록 실내 콘솔도 유지한다. 기존 광원, 플레이어, 동적으로 생성되는 광선 메시도 해당 카메라에서 계속 표시한다. 탐색 복귀가 완료되면 원래 camera cull mask로 복원한다.

이는 카메라의 렌더 필터이며 충돌 레이어, 물리 형상, 광선 레이캐스트, 기존 방 연결 그래프를 변경하지 않는다. 미니맵의 발견 셀·장치·문 데이터도 추가 공개하지 않는다. 검은 주변 여백은 다른 방을 제외한 전체 보기의 배경이며 새로운 가림 메시나 탐색 안개가 아니다.

## 실행 검증

- `VERIFY_REFLECTION.ps1`: 런타임 시작 및 **15개 검증 묶음 통과**. 기존 광학 수학·튜토리얼·진행·B/C 대표 퍼즐·A-01 실제 3회 반사·초기화·방 표시·카메라 이동·미니맵 탐색·잠금 자산 해시 검증 포함.
- 새 `camera_ui_test.gd`: V 진입/복귀, 부드러운 중간 상태, 거울별 선택과 정밀 회전, 자동 구도, 선택 중 명시적 탐색 복귀, 이동 중 방 중심 유지, 방 이탈, 방 밖 V 제한을 실제 엔진에서 검사한다.
- 장치 4개와 플레이어의 투영 좌표가 안전 영역 안에 있고 기본 HUD·미니맵·장치 카드에 가려지지 않는지 검사한다. 상세 버튼의 펼침/접기와 H/F1 표시도 확인한다.
- 전체 보기로 미니맵 발견 셀·장치 발견 정보가 바뀌지 않음을 비교했다. 다른 A 구역 바닥은 제외되고 A-01 바닥·기존 충돌 소품·조명은 유지되는지도 검사했다.
- 일반 화면과 1280×720, 1024×768, 800×1000 뷰포트에서 화면 비율에 따른 자동 구도를 검사했다. size는 고정 줌 값이 아니라 화면의 가용 공간에 따라 달라진다.
- 실제 휴대 발사기의 3회 반사 정답 광선을 전체 보기에서도 생성하고 수신기 활성·4개 광선 구간의 화면 내 표시를 확인했다.
- GPU OpenGL Compatibility에서 같은 테스트를 실행하고 탐색, 전체 보기, 거울별 조작, 정답 광로 화면을 `artifacts/camera_ui_*.png`로 저장했다. 개발 중 렌더 필터가 조명까지 제외하는 문제를 GPU 검수에서 발견해 조명 인스턴스도 유지하도록 수정했다.
- `git diff --check` 통과. headless 환경의 인증서 저장소 경고는 기존 환경 경고이며 프로젝트 스크립트 오류와 구분했다.

테스트는 실제 엔진의 자동 입력/호출과 렌더링에 기반한다. 장시간 수동 플레이나 모든 모니터 배율·극단적인 창 크기를 검수한 것은 아니다. 상세 안내/도움말/전체 지도는 사용자가 요청하는 펼침 화면이며, 도움말과 전체 지도 자체는 의도적으로 게임 화면 위에 표시한다.
